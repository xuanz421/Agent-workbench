# systematic debugging

1. Reproduce or characterize the failure.
2. Collect logs, state, inputs, and relevant call paths.
3. Find the earliest point where actual behavior diverges from expected behavior.
4. Form explicit hypotheses.
5. Test the smallest discriminating hypothesis first.
6. Implement the narrowest root-cause fix.
7. Run regression checks and summarize evidence.
